# Introduction à ASP.NET MVC par l’exemple (novembre 2013)

Ce dépôt contient la version **HTML** du document *Introduction à ASP.NET MVC par l’exemple*, publié initialement en **novembre 2013**. 

L’objectif est d’introduire, au travers d’exemples, les notions importantes de **ASP.NET MVC**, framework Web .NET basé sur le modèle **MVC (Modèle – Vue – Contrôleur)**. 

## Lire le document en ligne

* Site du document : [https://stahe.github.io/aspnetmvc-nov-2013/](https://stahe.github.io/aspnetmvc-nov-2013/)
* Version PDF : une version PDF du document est également disponible : [https://stahe.github.io/aspnetmvc-nov-2013/aspnetmvc-nov-2013.pdf](https://stahe.github.io/aspnetmvc-nov-2013/aspnetmvc-nov-2013.pdf) 

## Pré-requis

La compréhension des exemples nécessite peu de prérequis ; des **bases en C#** suffisent. 

Ressources conseillées :

* *Introduction au langage C#* : [http://tahe.developpez.com/dotnet/csharp](http://tahe.developpez.com/dotnet/csharp)
